# Build Pipeline — Implemented

## Architecture

```
Lerna 9 (independent versioning)
  + Nx 23 (build caching, topological ordering: ^build)
  + pnpm workspaces
  + tsup (ESM + DTS compilation)
  + GitHub Actions (CI/CD)
```

## Extension Chaining (matches Dhii `CompositeCachingServiceProvider::mergeExtensions`)

When multiple providers extend the same key, `composeProviders` chains them into a **single callable** per key:

```ts
// Dhii PHP (line 132-137):
// $merged[$key] = function ($c, $previous = null) use ($default, $extension) {
//     $result = $default($c, $previous);
//     $result = $extension($c, $result);
//     return $result;
// };

// Our JS equivalent:
composedExts[key] = (previous, container) => {
  const result = prev(previous, container);
  return ext(result, container);
};
```

No arrays. `Provider.extensions` stays `Record<string, Extension>`. Chaining is invisible to `DelegatingContainer`.

## Package Build Commands

## DI Package Source Structure

Barrel-based with separate concern files:

| File | Purpose |
|------|---------|
| `src/index.ts` | Barrel re-exports only |
| `src/types.ts` | Definition, Extension, Provider, Container, KeyInspection |
| `src/compose.ts` | composeProviders() |
| `src/containers.ts` | DelegatingContainer, CachingContainer, ProxyContainer, CompositeContainer |
| `src/circular.ts` | CircularDetector |
| `src/bootstrap.ts` | bootstrap() |
| `src/definitions.ts` | factory(), value(), alias(), construct() |
| `src/errors.ts` | DependencyError, MissingKeyError, CircularDependencyError |

## Module Resolution

Both package tsconfigs override to `module: "NodeNext"` / `moduleResolution: "NodeNext"` for correct CJS/ESM interop. All internal imports use explicit `.js` extensions.

## Testing

- `node:test` + `node:assert/strict` with tsx loader
- Tests run against compiled `dist/` output (package `exports` field enforced)
- Tests fail when dist is deleted, pass after build
- `vitest` removed from all packages and root

## Known Limitations

- PhpStorm cannot resolve `assert.strictEqual` from `node:assert/strict` (CJS `export =` namespace merge pattern). Tests pass fine at runtime.
